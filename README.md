# Yo'l yordamchisi

Telefon kamerasi orqali ishlaydigan brauzer ilovasi:

- polosa chiziqlari, polosalar soni va siz nechanchi polosadasiz;
- chiziqdan chiqib ketish ogohlantirishi;
- oldingi mashinagacha masofa va to'qnashuvgacha vaqt (AI: COCO-SSD);
- yon polosalardagi mashinalar va yuqoridan ko'rinish;
- yo'l belgilari (AQSh: SPEED LIMIT, STOP, YIELD, DO NOT ENTER, sariq romb; Yevropa/O'zbekiston belgilari);
- svetofor rangi, GPS bo'yicha tezlikni oshirish;
- avto-kalibrlash: telefon qanday o'rnatilgan bo'lsa ham gorizont va balandlikni o'zi topadi.

Ochish: https://abbosjon-dev.github.io/test-uchun/

O'quv prototipi, xavfsizlik tizimi emas.

Model: COCO-SSD (TensorFlow.js, Apache-2.0).
